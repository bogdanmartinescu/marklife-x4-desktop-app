# Test fixtures

Deterministic images, PDFs, and expected `.prn` files for ThermalBridge.

## Layout

```text
images/     PNG/JPEG fixtures for raster tests
pdf/        multi-page PDF fixtures
expected/   golden TSPL jobs generated by thermal-core
```

Once a fixture is physically verified on a Marklife X4, mark it `hardwareVerified: true` in `src/index.ts` and do not casually regenerate it.
